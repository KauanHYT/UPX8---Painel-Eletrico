# Customização

1. Substitua `Assets/Markers/wl03-equipment-target.png` pelo alvo do seu projeto.
2. Recrie a library pelo menu `WL03 > Configurar projeto completo` (apague a library anterior se necessário).
3. Ajuste largura e altura física no `WL03ProjectSetup.cs`.
4. Edite `Assets/Resources/wl03_procedure.json` para alterar o procedimento.
5. Ajuste as posições A/B/C em `WL03ProcedureController.CreateContextualContent`.
6. Substitua cubos por prefabs, setas, modelos 3D ou indicadores contextuais.
7. Valide o baseline antes de adicionar API, IoT ou visão computacional.
